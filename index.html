How I approach a technical problem

Clarify. Trace. Verify. Document.

1. Clarify the expected result. Define the input, output, constraints, and what “correct” means.

2. Trace the evidence. Inspect the data, state, logs, mappings, or workflow until the failure point is understood.

3. Verify the fix. Use reproducible checks, test data, and visible success/failure conditions.

4. Document the handoff. Leave clear notes, assumptions, limitations, and recovery steps so the solution is maintainable.
