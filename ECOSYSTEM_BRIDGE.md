# Education → Research → Portfolio → Career Bridge

This portfolio participates in Robert Sory's lightweight learning and career evidence pipeline.

## System flow

1. **Education / Knowledge Map** identifies a skill gap or verification target.
2. **Research / Project system** selects or generates a project that can naturally exercise the skill without distorting the research question.
3. **GitHub** receives reproducible, public-safe technical or analytical artifacts when a project reaches a publishable milestone.
4. **Portfolio** receives the human-readable case study, findings, methodology, visuals, and verified skill evidence.
5. **Career system** consumes portfolio evidence and verified mastery to update role-fit and search-tier decisions.

## Publication gates

- Project code or AI-assisted work is evidence of exposure, not automatic proof of independent mastery.
- Portfolio claims should use verified skill evidence whenever they imply personal capability.
- Research neutrality, source quality, privacy, and public/private boundaries override educational convenience.
- Private Luna implementation details are excluded unless explicitly approved for publication.
- A research topic should not be changed merely to manufacture a learning exercise.

## Required project metadata

Each education-linked project should identify:

- learning need
- target skill(s)
- required demonstration
- assessment or verification target
- GitHub output
- portfolio output
- career signal
- publication/privacy status

The canonical tracking records live in the Robert Knowledge Map and Research Master Project Tracker in Google Drive.
